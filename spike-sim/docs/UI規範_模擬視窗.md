# UI 規範：模擬視窗（元件模擬、接口連接）v1

2026-11-18 · 設計：Opus · 實作：Sonnet · made by 資訊老師黃博胤

## 0. 要解決的問題（老師回饋）
1. 元件模擬的 3D 視窗太小；同時有兩個零件時，要把瀏覽器縮得很小才看得清楚。
2. 元件模擬最上面那排 A～F 接口（`.portstrip`）不需要了：**接口一律在「接口連接」分頁插拔**。

根本原因：右側欄固定 `width:500px`（`.side`），`#tab-comp` 又把所有零件硬塞進一個螢幕高（`grid-auto-rows:minmax(0,1fr)`），零件越多每格越扁，3D 畫面只剩一小塊。

## 1. 右側欄寬度（全域）
- 加一條**可拖曳的分隔線**（`.splitter`，寬 8px，滑鼠游標 `col-resize`），放在 `.coding` 與 `.side` 之間。拖曳改變 `.side` 寬度：最小 420px，最大 `視窗寬 − 520px`（積木區至少留 520px）。
- 每個分頁記住自己的寬度（`localStorage` 鍵 `spikesim.sideW.field`／`.comp`／`.wire`，讀寫都包 try/catch）。
- 預設寬度：場地模擬 500px；**元件模擬、接口連接預設 `max(560px, 50vw)`**（仍受上面的最大值限制）。
- 切換分頁時，側欄寬度用 `transition: width .18s` 換成該分頁的寬度；切換後觸發一次 `resize` 事件，讓 3D 視窗與場地畫布重算尺寸。
- `viewtabs` 右邊加一顆「⤢ 放大」切換鈕（`#btn-widen`，`aria-pressed`）：按下時側欄寬度 = `視窗寬 − 520px`（積木區縮到最小），再按回到記住的寬度。按鈕文字切換「⤢ 放大」／「⤡ 還原」。
- 視窗寬 < 1100px 時隱藏分隔線與放大鈕，側欄維持 500px（只做電腦版，不做手機）。

## 2. 元件模擬版面（`#tab-comp`）
- **移除 `.portstrip`**（整排 A～F 與「拖到接口插上」）。`comp.js` 裡建立 strip、`renderStrip`、`chipDrag` 相關程式不要再放進畫面（可保留函式但不 append；或整段刪除，擇一，保持 `connect()` 自動接上的行為）。
- 原位置改成一行**接口提示列**（`.comp-portline`，高 32px）：左邊依序顯示目前程式用到的零件與接口，例如「馬達 A　顏色感測器 C」（小色點＋文字）；右邊一顆按鈕「到接口連接改接口 →」，按了切到「接口連接」分頁。程式寫的接口和實際插的不一致時，該項變紅字並加「⚠ 沒接」。
- 刪掉 `#tab-comp` 的 `min-height: min(720px, …)` 與 `.comp-grid` 的 `grid-auto-rows: minmax(0, 1fr)`／`n5~n8` 的固定 270px 規則。**零件格高度由寬度決定，不再擠進一個螢幕高**；側欄本來就能垂直捲動。
- 欄數規則（用 `ResizeObserver` 量 `.comp-grid` 寬度 W，設 CSS 變數 `--cols`）：
  - 每格最小寬 380px：`cols = clamp(1, floor((W + 10) / 390), 零件數)`。
  - 1 個零件：1 欄，3D 區高度 = `min(寬 × 3/4, 100vh − 260px)`。
  - 2 個零件：W ≥ 780 並排兩欄，否則上下兩格各佔滿寬。
- 3D 區（`.p3d-host`）比例 4:3，**最小高度 300px**；平面版零件（沒有 WebGL 時）同樣最小高 300px。

## 3. 零件卡（`.part`）外觀
- 標題列（36px）：色點、名稱、接口標籤（黑底白字 `A`）**靠右的一組小工具**：視角按鈕「立體／上視／正視／側視」改成小圖示按鈕（文字太長時只留「立體」「上視」兩個＋「⤢」）、「⤢ 全螢幕」鈕。原本 3D 下方那排 `.p3d-bar` 移除，改放標題列，省下一列高度。
- 數值列（`.part-f`）一行，字級 13px；說明文字（`.part-hint`）預設收起，改成標題列一個「?」圓鈕，滑鼠移上去或點一下才顯示（tooltip 或展開一行皆可）。
- 卡片圓角 14px、內距 8px；卡與卡間距 12px。

## 4. 單一零件全螢幕
- 標題列「⤢」：把該零件卡移到一個全畫面覆蓋層（`.part-full`，背景 `rgba(15,23,42,.55)`，卡片置中 `92vw × 88vh`），3D 區撐滿；按「✕」、Esc 或點背景回到原位置（把 DOM 節點搬回原來的 `.comp-grid` 位置，不要重建零件，避免 WebGL 重新建立）。
- 搬動後觸發 `resize`，`ResizeObserver` 會讓 3D 重算尺寸。

## 5. 接口連接（`#tab-wire`）
- 使用同一套側欄寬度規則（預設 `max(560px, 50vw)`）。
- `.wire-svg` 寬度 100%，`max-height: calc(100vh − 230px)`，高度依比例；放大後零件卡、插頭、接口都要比現在大。
- 說明文字移到 SVG 上方，字級 13px。

## 6. 不要動的東西
- `sim.ports` 仍是唯一資料來源；接口連接、主機與裝置的下拉選單、元件模擬都讀它。
- 3D 互動、`SP.p3dViews`、`v.project` 除錯介面維持可用。
- 場地模擬分頁的版面不變（只受側欄寬度影響）。
- 不寫「今天不用○○」這類設計說明在畫面上。

## 7. 驗收（實作者自測，截圖給 Opus 看）
用 `resize_window` 設 1600×900 與 1280×800 兩種尺寸，各截圖：
1. 元件模擬，只有 1 個零件（主機）：3D 區寬度 ≥ 側欄寬 − 40px，高度 ≥ 400px（1600×900 時）。
2. 元件模擬，2 個零件（`SP.compForce=['motor:A','force:B']`）：放大前、按「⤢ 放大」後各一張；放大後兩格並排、每格 3D 寬 ≥ 420px。
3. 6 個零件：不擠扁，側欄可捲動，每格 3D 最小高 300px。
4. 單一零件全螢幕開關各一次，回原位後 3D 正常轉動（`SP.p3dViews` 數量不變）。
5. 拖分隔線改寬度、切分頁再切回來，寬度有記住。
6. 元件模擬最上面不再有 A～F 接口列；接口提示列能正確顯示、按鈕能切到接口連接。
7. 主控台沒有錯誤（LDraw 找檔的 404 可忽略）。
