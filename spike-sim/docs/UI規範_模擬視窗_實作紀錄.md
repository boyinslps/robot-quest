## 改了哪些檔
- index.html：加 meta author、`#splitter` 分隔線、`#btn-widen` 放大鈕、右下角署名。
- style.css：刪掉舊的 #tab-comp min-height、comp-grid 固定列高與 n3~n8 規則、舊 .part/.p3d-bar 規則；檔尾新增「模擬視窗版面」區塊（側欄、分隔線、接口提示列、零件卡、全螢幕、接口連接）。

- ports.js 未改（說明文字用 CSS order 移到 SVG 上方）。

## 偏離規範之處
1. 欄數公式改成 `floor((W+12)/382)`（規範 `(W+10)/390`）。原因：預設側欄 800px 時格子內容寬只有 764（捲軸、內距吃掉），照規範兩個零件會上下疊；改後 1600 寬預設就能並排（每格 3D 約 366×300）。
2. 視角按鈕：立體／上視永遠顯示，正視／側視只在卡片寬 ≥470px 時顯示（CSS container query）。
3. 1 個零件、側欄 800 時 3D 寬 746（規範 ≥760）：側欄內距、捲軸與卡片內距 8px 吃掉，未再壓縮。
4. 「放大」對所有分頁生效（含場地模擬），按分隔線拖曳會自動取消放大。
5. 全螢幕開著時零件清單改變，會先自動關閉全螢幕再重排。
6. 側欄在視窗 <1100px 時維持 500px（沿用原本 <1000px 的堆疊版面不動）。
