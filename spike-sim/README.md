# SPIKE 模擬器

給學生練習 LEGO SPIKE 的線上模擬器：用積木或 Python 寫程式，在模擬場地裡看機器人怎麼動。
這是**獨立的小工具**，和根目錄的「機器人闖關（篩選測驗）」、教師後台沒有任何程式或資料上的關聯。

## 怎麼開

### 本機（不需要網路）

這個資料夾已經內含所有需要的函式庫（`vendor/`：Blockly、Three.js、Python 執行環境），**完全離線也能跑**。

- **Windows**：雙擊 `啟動模擬器.bat`（黑色視窗不要關，瀏覽器會自動打開）。沒裝 Python 時會改用內建的 PowerShell（沒在實機測過），建議直接 `winget install -e --id Python.Python.3.12`。
- **Mac／Linux**：終端機執行 `bash 啟動模擬器.command`。

不能直接雙擊 `index.html`：瀏覽器會擋掉 3D 模組和 Python 執行環境（要用網址開）。詳細說明、進度存在哪裡、怎麼把本機改的東西推回 GitHub，看 [本機使用說明.md](本機使用說明.md)。

### 給學生使用（線上網址）

倉庫已經用 GitHub Pages 發佈，所以**合併到 `main` 後不用另外設定**，模擬器會自動出現在子路徑：

> `https://boyinslps.github.io/robot-quest/spike-sim/`

根網址 `https://boyinslps.github.io/robot-quest/` 仍然是篩選測驗，兩者互不影響。第一次發佈要等 1～2 分鐘；之後 `spike-sim/` 有更新、合併到 `main` 就會自動更新。所有函式庫都放在同一個網站裡（`vendor/`），學校網路擋外部網站也不影響。

## 功能

- **連續捲動的積木抽屜**（和官方一樣）：左側彩色圓形類別列只是捷徑，所有類別接成一條清單、每段有標題；點類別會跳到那一段，往下捲會自動換到下一個類別；抽屜常駐，拖出積木後不會收起來。
- 左側彩色圓形類別列：**馬達、移動、燈光、聲音、事件、控制、感測、運算、變數、我的積木**；Scratch 風格積木；右下角綠色執行鈕。**類別顏色取自官方 SPIKE App 截圖**（馬達藍 `#0090f5`、移動粉紅 `#ff4ccd`、燈光淺紫 `#b896f8`、聲音紫 `#c061f1`、事件黃 `#f5c402`、控制橘 `#ffb515`、感測青 `#34ccf1`、運算綠 `#00b94d`、變數橘 `#ff8f24`），馬達／移動／燈光／聲音／事件／感測積木左邊有白色圓形圖示。「我的積木」的顏色沒有官方截圖可對照。積木名稱、參數與預設值（馬達速度 75 %、移動速度 50 %、1 圈馬達旋轉 = 17.5 公分）依照 LEGO 官方 Word Blocks 說明。
- **積木 ↔ Python 切換**：積木會轉成 SPIKE App 3 風格的 Python（常數與函式簽名依官方 Python API 參考），Python 可直接修改並在模擬器執行（Pyodide，第一次載入約 10 MB）。Python 改過後不會變回積木。
- **報錯台**：執行前檢查積木（沒有事件積木、埠不符、馬達不在 A/B、缺條件、孤立積木）；執行時的錯誤與警告（含 Python，翻成中文並標出第幾行）列在報錯台，點一下跳到積木或程式行。
- 6 種場地、主機（5×5 燈陣、可旋轉方向、電源鍵燈色、**可按住的左右按鈕**）、**A～F 六個接口都能接任何零件**（馬達、顏色、距離、力、空著；預設 A、B 是馬達，C 顏色、D 距離、E 力）。
- 每個「當…」積木是獨立執行緒，可同時執行；支援傳送／接收訊息（含「傳送並等待」）、「停止其他積木堆疊」、我的積木。
- **布置場地**：按「布置場地」，在場地上拖曳畫出**方塊**（機器人推得動）、**牆**（固定）、**色紙**與**膠帶線**（顏色感測器看得到），用橡皮擦刪除；可以改大小、切換「機器人推得動」、「設為起點」；放的物件會跟著專案一起存檔。距離感測器、力感測器（碰撞探針）都會偵測到這些物件。
- **清除數據**（右邊「元件模擬」旁的按鈕）：馬達位置／圈數、相對位置、偏航角、計時器、主機的燈與文字、距離感測器的燈、輕拍次數、行駛軌跡、輸出訊息一次歸零；不會動到車子的位置、不會停掉執行中的程式、不會動到積木。LEGO 沒有「一次清全部」的積木，官方是分開的：「重設計時器」、「將相對位置設為 0」、「將偏航角設為 0」（Python：`motion_sensor.reset_yaw`、`motor.reset_relative_position`、`motion_sensor.reset_tap_count`、`light_matrix.clear`）；折線圖／長條圖的「清除」積木，模擬器還沒做圖表。
- **全螢幕**：把場地放大（上課投影用），全螢幕裡有執行／停止鈕與即時讀數，也可以布置場地。
- **用手按力感測器**：按住「按住：用手按力感測器」就等於用手壓著它；主機的左右按鈕也可以用滑鼠按住。
- **3D 車子**：「場地」旁邊的「3D 車子」分頁，用 Three.js 顯示**整個場地**（地板圖案、牆、方塊、色紙、膠帶、行駛軌跡）和小車**實際的位置與方向**，場地改了 3D 會同步；鏡頭可「跟隨小車」或看「場地全景」。小車用滑鼠拖曳旋轉、滾輪縮放、右鍵平移，有立體／正視／側視／上視／後視快速視角；程式跑起來時**輪子會跟著馬達轉**（角度就是馬達編碼器的度數）、燈陣、電源鍵燈、左右按鈕、顏色感測器的小燈也會同步。只開一顆馬達時，車子會繞著另一顆輪子轉。**這是依模擬器尺寸（輪徑 5.6 公分、輪距 11.2 公分）簡化的示意模型，不是官方三視圖或官方 3D 檔**（官方網站在建置時連不上，沒有取得三視圖與官方尺寸）。
- **學習任務（跟著做）**：首頁有 10 個引導任務，做法比照 LEGO 官方入門教學——一開始是空的程式區，一步一步帶學生拼積木：
  - 入門六課（對應六個零件）：母體燈、馬達、顏色感測器、距離感測器、力傳感器、陀螺儀；另有四個挑戰：走正方形、看到黃色就停、遇牆就轉彎、黑線循線。
  - 右側最上面是「目前任務」卡片：第幾步／共幾步、這一步要做什麼、小提示、進度點，可按左右箭頭前後翻。
  - 左邊積木盤**只留這一課需要的積木和類別**；要拿的積木會用橘色框標出，所在的類別也會圈起來，程式區用虛線框和**手勢拖曳動畫**指出「拖到哪裡」（接在哪一塊下面、放進哪個 C 字形或空格）。
  - 改積木上的數字或選項、按執行、動手試（把色塊拖進框、按住力傳感器、拖主機傾斜…）也都有橘色光圈指出位置。
  - 系統會自動偵測學生有沒有做到，做到就打勾並換下一步；程式還在跑時，遇到「再按一次 ▶」的步驟會先自動停掉，讓學生看得到 ▶。
  - 每一課做完有結束畫面（回首頁選下一個、再做一次）；中途按「離開」會恢復完整積木盤，保留目前做的程式。
  - Python 範例另外放在首頁的「Python 範例」，不是引導任務。
- **兩個模擬畫面，可以切換**（右側上方）：
  - **場地模擬**：車子在場地上跑（場地、3D 車子、布置場地、全螢幕、主機與裝置都在這裡）。
  - **元件模擬**：偵測左邊積木（或 Python）用到哪些零件，**只把用得到的零件放出來**；零件多就自動分割畫面（1～2 個一欄、3～4 個兩欄、5 個以上每格固定大小可捲動），方便看到多個零件一起動，例如「按下力傳感器 → 馬達轉動」。切換頁籤上的黃色數字是目前用到的零件數。
  - 零件依官方入門的順序排列：母體燈、馬達、顏色感測器、距離感測器、力傳感器、陀螺儀。零件接在積木指定的埠（A～F），**新出現的零件，如果那個埠是空的就會自動接上**；那個埠接的是別的零件就會亮紅框提醒。學生自己拔掉的不會被偷偷插回去。
  - **主機接口**（元件模擬最上面一排）：A～F 六個插槽。用滑鼠從右邊托盤把零件拖到插槽＝插上；拖到另一個插槽＝換位置（對方有零件就互換）；拖到外面＝拔掉。程式寫的埠和零件插的埠對不上時，會報「埠 A 沒有接馬達」這類清楚的錯誤。
  - **全部用滑鼠直接操作，沒有滑桿也沒有按鈕**：
    - 母體燈：直接按住畫面上的左、右按鈕；5×5 燈、電源鍵燈色會即時顯示。
    - 馬達：在轉盤上拖曳，就像用手轉馬達；顯示位置 0～359°、共轉幾圈、轉速。
    - 顏色感測器：把色塊（紅黃綠藍黑白）拖到感測器下面的框裡，拖走就是拿開；拖著停在框裡時感測器就已經看得到。
    - 距離感測器：左右拖動灰色物體，拖到最右邊就是拿開（200 公分以上＝沒偵測到）；感測器上的 4 顆燈也會顯示。
    - 力傳感器：用滑鼠按住黑色圓鈕，按得越久力越大（0～10 牛頓），放開就鬆開。
    - 陀螺儀：拖著主機傾斜（上下＝俯仰、左右＝滾動），放開會回到平放；拖外面的圈＝轉向（偏航）；快速左右甩動＝搖晃；點一下＝輕拍。
  - 進入「元件模擬」時車子等於放在桌上（輪子懸空，不會在場地移動），所以感測器只讀你手上給的東西，沒有放東西就是「沒有東西／沒偵測到」；切回「場地模擬」就全部放開，恢復讀場地。
  - 入門六課會自動切到「元件模擬」，挑戰任務會切到「場地模擬」。另有「認識接口」一課：故意把馬達從 A 拖到 C，看程式為什麼不動，再拖回 A。
- 機器人設定：輪徑、輪距、轉向角度方向可校正，並有「真實模式」（馬達加減速、兩輪 ±1% 誤差）。
- 首頁（新專案、繼續、開啟檔案、積木與 Python 範例）；可儲存／開啟 `.json`，並自動保存在瀏覽器。

## 模擬的規格與限制

- 場地 300 × 200 公分，3 px = 1 公分；預設輪徑 56 mm、輪距 112 mm（請依你們的車型校正）。
- 碰撞：車身（旋轉後的矩形）和障礙物做精確相交判斷，小方塊、細牆、斜著撞都不會穿過；拖曳車子或把障礙物畫在車子上會被擋住。
- 馬達的加減速：馬達用固定的減速度（4000 度/秒²）煞車，所以不同速度的移動時間差距符合直覺；主機面板的馬達角度顯示 0～359° 加上「共轉幾圈」，Python 的 `relative_position` 仍是累計度數。
- **移動馬達組**：預設 A＝左輪、B＝右輪，可以用「設定移動馬達為」積木或 Python 的 `motor_pair.pair(motor_pair.PAIR_1, port.C, port.D)` 改成別的埠；組內有一顆不是馬達時，移動積木會報錯。每次按執行都會還原成 A+B。C～F 上的馬達只會轉，不會帶動車子。
- 學習任務的接法和官方入門一致：顏色、距離感測器接 A，力傳感器接 B（馬達在 A）。
- 「元件模擬」裡的色塊、物體距離、手按的力、主機傾斜是疊在模擬之上的覆寫值，不是物理模擬；離開「元件模擬」就會全部放開。
- 陀螺儀的俯仰／滾動正負號、「朝上的面」對應、顏色感測器 RGB 數值範圍、距離感測器 4 顆燈的排列，**都沒有用真機驗證**。
- 「速度 %」換成度/秒時用 1 % = 10 度/秒（100 % = 1000 度/秒）；官方沒有公布確切換算，**這是推測值**。
- 「1 圈馬達旋轉 = 17.5 公分」是官方預設，實際輪子一圈是 π × 輪徑；兩者不同時，移動「公分」會有小誤差，和真機一樣可以用「設定 1 圈馬達旋轉」校正。
- 距離感測器用 5 條射線偵測，顏色感測器讀場地底圖像素。
- 原始 yaw（`motion_sensor.tilt_angles()[0]`）為逆時針為正，依據 LEGO 範例推論，**尚未用真機驗證**；積木的「轉向角度」預設順時針為正，可在設定改。
- 執行 Python 前會自動在 `while`／`for` 迴圈開頭補上 `await`，所以 LEGO 範例裡沒寫 `await` 的迴圈也不會讓網頁凍結（但不在 `async def` 裡的迴圈無法處理）。
- **官方入門頁的寫法可以直接貼**（2026-11-17）：`time.sleep_ms(x)` 單獨一行時，執行前自動改成 `await`（最外層、`async def`、以及有用到它的一般 `def` 都會處理）；`motor.run_for_degrees`、`motor.run_for_time`、`light_matrix.write`、`sound.beep`、`motor_pair.move_for_*` 這類「可等待」的函式，不寫 `await` 也會立刻開始做、程式繼續往下，寫了 `await` 才會等它做完；程式最後一行跑完後，會等已經開始的動作（馬達、燈陣文字）做完才結束。`sound.stop()` 會中止還在響的嗶聲。

|---|---|
| `index.html`、`style.css`、`app.js` | 介面與執行流程 |

| `pygen.js` | 積木 → Python 產生器 |
| `pyrun.js` | Pyodide 執行環境與 SPIKE Python API 子集、Python 錯誤解析 |

## 2026-11-17 改版：真實零件外觀
