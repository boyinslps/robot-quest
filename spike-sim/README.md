# SPIKE 模擬器

給學生練習 LEGO SPIKE 的線上模擬器：用積木或 Python 寫程式，在模擬場地裡看機器人怎麼動。
這是**獨立的小工具**，和根目錄的「機器人闖關（篩選測驗）」、教師後台沒有任何程式或資料上的關聯。

## 怎麼開

直接用 Chrome 開 `spike-sim/index.html` 即可（需要網路，Blockly 與 Python 執行環境從 `cdn.jsdelivr.net` 載入）。

> **3D 小車預覽需要用網址開啟**（線上的 GitHub Pages 可以）。瀏覽器不允許「雙擊檔案開啟」載入 3D 模組，這時只有 3D 分頁不能用，其他功能都正常。要在本機用 3D，請在 `spike-sim/` 資料夾開一個網頁伺服器，例如 `python3 -m http.server`，再開 `http://localhost:8000/`。

### 給學生使用（線上網址）

倉庫已經用 GitHub Pages 發佈，所以**合併到 `main` 後不用另外設定**，模擬器會自動出現在子路徑：

> `https://boyinslps.github.io/robot-quest/spike-sim/`

根網址 `https://boyinslps.github.io/robot-quest/` 仍然是篩選測驗，兩者互不影響。第一次發佈要等 1～2 分鐘；之後 `spike-sim/` 有更新、合併到 `main` 就會自動更新。

學校網路若擋 `cdn.jsdelivr.net`，積木與 Python 模式都會打不開。

## 功能

- 左側彩色圓形類別列：**馬達、移動、燈光、聲音、事件、控制、感測、運算、變數、我的積木**；Scratch 風格積木；右下角綠色執行鈕。**類別顏色取自官方 SPIKE App 截圖**（馬達藍 `#0090f5`、移動粉紅 `#ff4ccd`、燈光淺紫 `#b896f8`、聲音紫 `#c061f1`、事件黃 `#f5c402`、控制橘 `#ffb515`、感測青 `#34ccf1`、運算綠 `#00b94d`、變數橘 `#ff8f24`），馬達／移動／燈光／聲音／事件／感測積木左邊有白色圓形圖示。「我的積木」的顏色沒有官方截圖可對照。積木名稱、參數與預設值（馬達速度 75 %、移動速度 50 %、1 圈馬達旋轉 = 17.5 公分）依照 LEGO 官方 Word Blocks 說明。
- **積木 ↔ Python 切換**：積木會轉成 SPIKE App 3 風格的 Python（常數與函式簽名依官方 Python API 參考），Python 可直接修改並在模擬器執行（Pyodide，第一次載入約 10 MB）。Python 改過後不會變回積木。
- **報錯台**：執行前檢查積木（沒有事件積木、埠不符、馬達不在 A/B、缺條件、孤立積木）；執行時的錯誤與警告（含 Python，翻成中文並標出第幾行）列在報錯台，點一下跳到積木或程式行。
- 6 種場地、主機（5×5 燈陣、可旋轉方向、電源鍵燈色、**可按住的左右按鈕**）、A～F 埠裝置（C～F 可選顏色／距離／力感測器）。
- 每個「當…」積木是獨立執行緒，可同時執行；支援傳送／接收訊息（含「傳送並等待」）、「停止其他積木堆疊」、我的積木。
- **布置場地**：按「布置場地」，在場地上拖曳畫出**方塊**（機器人推得動）、**牆**（固定）、**色紙**與**膠帶線**（顏色感測器看得到），用橡皮擦刪除；可以改大小、切換「機器人推得動」、「設為起點」；放的物件會跟著專案一起存檔。距離感測器、力感測器（碰撞探針）都會偵測到這些物件。
- **全螢幕**：把場地放大（上課投影用），全螢幕裡有執行／停止鈕與即時讀數，也可以布置場地。
- **用手按力感測器**：按住「按住：用手按力感測器」就等於用手壓著它；主機的左右按鈕也可以用滑鼠按住。
- **3D 車子**：「場地」旁邊的「3D 車子」分頁，用 Three.js 顯示小車，滑鼠拖曳旋轉、滾輪縮放、右鍵平移，有立體／正視／側視／上視／後視快速視角；程式跑起來時**輪子會跟著馬達轉**（角度就是馬達編碼器的度數）、地板會往後捲、燈陣、電源鍵燈、左右按鈕、顏色感測器的小燈也會同步。**這是依模擬器尺寸（輪徑 5.6 公分、輪距 11.2 公分）簡化的示意模型，不是官方三視圖或官方 3D 檔**（官方網站在建置時連不上，沒有取得三視圖與官方尺寸）。
- 機器人設定：輪徑、輪距、轉向角度方向可校正，並有「真實模式」（馬達加減速、兩輪 ±1% 誤差）。
- 首頁（新專案、繼續、開啟檔案、積木與 Python 範例）；可儲存／開啟 `.json`，並自動保存在瀏覽器。

### 和官方 Word Blocks 的對照

| 官方類別 | 狀態 |
|---|---|
| 馬達（轉動 圈／度／秒、轉到位置、開始／停止、速度、位置、相對位置） | 已做（只有 A、B 兩顆馬達） |
| 移動（移動 圈／度／公分／英寸／秒、轉向、開始、停止、速度、設定馬達、1 圈 = N 公分、左右輪各自速度） | 已做（馬達組只支援 A+B） |
| 燈光（5×5 圖案、寫入、像素、亮度、旋轉／方向、電源鍵燈） | 已做；圖案是近似畫法，只有 27 種（官方 67 種）；沒有 3×3 彩色燈陣與距離感測器燈 |
| 聲音（嗶聲、開始嗶聲、停止） | 已做；沒有音效檔、音量、音高效果 |
| 事件（程式開始、顏色、力、距離、按鈕、計時器、條件、訊息） | 已做；**沒有**傾斜、朝向、搖晃（機器人平放在地上） |
| 控制、運算、變數、我的積木 | 已做；清單沒有做 |
| 感測（顏色、反射光、力、距離、偏航角、按鈕、計時器） | 已做；俯仰、滾動固定為 0 |
| 音樂、折線圖、長條圖、顯示器、天氣、加速度／角速度等擴充 | **沒有做**（Python 會明確報「模擬器尚未支援」） |

非官方、為了教學方便加的積木：「向右／左轉 N 度（陀螺儀）」、「印出到訊息欄」。

## 模擬的規格與限制

- 場地 300 × 200 公分，3 px = 1 公分；預設輪徑 56 mm、輪距 112 mm（請依你們的車型校正）。
- 馬達 A＝左輪、B＝右輪；Python 的 `motor_pair` 目前只支援 A、B。
- 「速度 %」換成度/秒時用 1 % = 10 度/秒（100 % = 1000 度/秒）；官方沒有公布確切換算，**這是推測值**。
- 「1 圈馬達旋轉 = 17.5 公分」是官方預設，實際輪子一圈是 π × 輪徑；兩者不同時，移動「公分」會有小誤差，和真機一樣可以用「設定 1 圈馬達旋轉」校正。
- 距離感測器用 5 條射線偵測，顏色感測器讀場地底圖像素。
- 原始 yaw（`motion_sensor.tilt_angles()[0]`）為逆時針為正，依據 LEGO 範例推論，**尚未用真機驗證**；積木的「轉向角度」預設順時針為正，可在設定改。
- 執行 Python 前會自動在 `while`／`for` 迴圈開頭補上 `await`，所以 LEGO 範例裡沒寫 `await` 的迴圈也不會讓網頁凍結（但不在 `async def` 裡的迴圈無法處理）。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html`、`style.css`、`app.js` | 介面與執行流程 |
| `sim.js` | 物理、感測器、場景、場地布置（方塊／牆／色紙／膠帶、推動） |
| `api.js` | 積木與 Python 共用的模擬器 API（馬達、移動、燈光、感測、訊息…） |
| `car3d.js` | 3D 小車預覽（Three.js，ES 模組，需要用網址開啟） |
| `blocks.js` | 積木定義、JavaScript 程式產生器、工具箱、配色與圖示 |
| `pygen.js` | 積木 → Python 產生器 |
| `pyrun.js` | Pyodide 執行環境與 SPIKE Python API 子集、Python 錯誤解析 |
