# SPIKE 模擬器：本機使用說明

這個資料夾**不需要網路**就能跑（`vendor/` 裡有 Blockly、Three.js、Python 執行環境），而且和 GitHub 是連在一起的（它本來就是 `boyinslps/robot-quest` 的一部分）。

## 一、打開模擬器

不能直接雙擊 `index.html`（瀏覽器會擋 3D 和 Python）。用下面其中一種：

**Windows**：雙擊 `啟動模擬器.bat`。黑色視窗不要關，瀏覽器會自動打開。
或在這個資料夾打開 PowerShell／命令提示字元，貼上：

```bash
py -3 -m http.server 8765 --bind 127.0.0.1
```

然後用瀏覽器開 <http://127.0.0.1:8765/>。（沒有 `py` 的話把 `py -3` 換成 `python`。）

**Mac／Linux**：

```bash
bash 啟動模擬器.command
```

或：

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

用完關掉黑色視窗（或按 Ctrl+C）就結束了。

### 如果出現「無法辨識 'py'」（這台電腦沒裝 Python）

兩個辦法，擇一：

1. **裝 Python（最穩，建議）**：在 PowerShell 貼上這行（Windows 10／11 內建 winget，約 1～2 分鐘）：

```bash
winget install -e --id Python.Python.3.12
```

裝完**把 PowerShell 整個關掉再重開**（不然還是找不到），回到 `spike-sim` 資料夾再貼 `py -3 -m http.server 8765 --bind 127.0.0.1`。
沒有 winget 的話，到 <https://www.python.org/downloads/> 下載安裝，安裝畫面第一頁一定要勾「Add python.exe to PATH」。

2. **不裝任何東西**：在 `spike-sim` 資料夾的 PowerShell 貼上這行，改用 Windows 內建的方式啟動（資料夾裡的 `啟動模擬器.bat` 在找不到 Python 時也會自動這樣做）：

```bash
powershell -NoProfile -ExecutionPolicy Bypass -File .\serve.ps1
```

然後開 <http://localhost:8765/>。**這個備用方式我沒有在 Windows 上測過**（開發環境是 Linux），如果不行請把紅色錯誤訊息拍給老師看，改用第 1 個辦法。

### 如果「localhost 拒絕連線」

代表小伺服器沒有真的跑起來。請看黑色視窗最後幾行寫什麼：

- **「Python was not found」或跳出 Microsoft Store**：這台電腦沒有真的 Python（Windows 內建的 `python.exe` 只是商店捷徑）。裝 Python（<https://www.python.org/downloads/>，安裝時勾「Add python.exe to PATH」），或直接用資料夾裡的 `啟動模擬器.bat`，它會自動改用 Windows 內建的 PowerShell。
- **「Address already in use」**：8765 已經被別的程式占用。把指令裡的 8765 換成 8766，網址也跟著換。
- **視窗一閃就不見**：用命令提示字元（不是雙擊）開 `啟動模擬器.bat`，看錯誤訊息。

## 二、第一次設定 Git（只要做一次）

1. 安裝 Git：<https://git-scm.com/download/win>（Mac 在終端機輸入 `git --version` 會自動提示安裝）。
2. 告訴 Git 你是誰：

```bash
git config --global user.name "你的名字"
git config --global user.email "你的GitHub信箱"
```

3. 第一次推送時，會跳出瀏覽器要你登入 GitHub 並授權，登入一次之後就記住了。

## 三、取得專案（還沒有這個資料夾的人）

```bash
git clone https://github.com/boyinslps/robot-quest.git
cd robot-quest
git checkout claude/gracious-sagan-lejjyg
cd spike-sim
```

（等這個分支合併到 `main` 之後，就不用 `git checkout` 那行了。）

## 四、本機改完推回 GitHub

在 `robot-quest` 資料夾裡（不是 `spike-sim` 裡面也可以，Git 會自己找到）：

```bash
git status
git add -A
git commit -m "說明你改了什麼"
git push
```

- 推到**自己的分支**（例如上面的 `claude/gracious-sagan-lejjyg`）：線上網站**不會**變，要到 GitHub 網頁按「Compare & pull request」再合併，才會更新線上版。
- 想直接改線上版：先 `git checkout main`、`git pull`，改完再 `git push`。`main` 一更新，`https://boyinslps.github.io/robot-quest/spike-sim/` 會在 1～2 分鐘內跟著更新。**學生正在用的時候不建議直接推 `main`**。
- 推不上去時，把紅色的錯誤訊息拍給老師看。常見的是「Updates were rejected」：先 `git pull` 再 `git push`。

## 五、搭配學習單時要注意

- 學生的進度（目前的程式、設定）自動存在**瀏覽器**裡，而且和網址綁在一起：`127.0.0.1:8765` 和 `localhost:8765`、`127.0.0.1:8766` 是三份不同的存檔。請固定用同一個網址、同一個瀏覽器、不要開無痕視窗。
- 要交作業或換電腦，按畫面上方的「儲存」下載 `.json`，要用時按「開啟」。
- 首頁的「學習任務」有 11 個引導任務，順序和 LEGO 官方入門一致。
- 「清除數據」按鈕在「場地模擬／元件模擬」那一排。

## 六、限制

- Windows 的 `啟動模擬器.bat` 和備用的 `serve.ps1` 沒有在 Windows 實機上測過（開發環境是 Linux）。
- 陀螺儀正負號、顏色數值範圍、距離感測器 4 顆燈的排列沒有用真機驗證；沒有 LEGO 的音效檔。
